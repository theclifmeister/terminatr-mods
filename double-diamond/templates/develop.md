# Develop: {title}

Double diamond, Develop: one solution option for a design, a spike run
beside the other options. Time-boxed: prove or disprove the option, not
production code. Your report's `## Check` says how to judge this option
against the design's success criteria (what to run or read, and what a
good result looks like). Code you write stays on your branch: it isn't
merged; the picked option is built in Deliver.

## Steps

- Read the design's problem statement and success criteria
- Try the option on the riskiest part first
- Write up what you found, its cost and its risks
- Report, with a Check that judges it against the success criteria
