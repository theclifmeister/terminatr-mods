# Define: {title}

Double diamond, Define: one problem. The output is a short write-up,
attached to your report: a problem statement (who has it, what it costs,
in two or three sentences, as an extension of PROJECT.md's goal),
success criteria (how we will know it is solved) and open questions for
the user. No code.

## Steps

- Read the Discover reports and memory notes on this problem
- Write the problem statement
- Write the success criteria
- List the open questions, each with the options you see
- Attach the write-up and report
